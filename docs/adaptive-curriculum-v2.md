# Adaptive Curriculum – Leitplanken

Priorität: fällige Wiederholungen → schwache Mastery-Werte → aktive Produktion → neuer Stoff.

Der lineare Kurs bleibt jederzeit verfügbar. Adaptiv bedeutet nicht zufällig: Empfehlungen werden aus Spaced Repetition, Fehlerhäufigkeit, Wort-/Grammatik-Mastery und Skill-Mastery abgeleitet. Ein einzelner Fehler reicht nicht für eine dauerhafte Schwäche-Klassifikation.
